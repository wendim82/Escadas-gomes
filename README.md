# Escadas Gomes

Site institucional da Escadas Gomes — projetos e execução de escadas de concreto e alvenaria em toda Minas Gerais.

- Hero com escada isométrica 3D (Three.js) animada por scroll (GSAP ScrollTrigger)
- Catálogo de modelos com botão de interesse pelo WhatsApp
- Mapa de Minas Gerais (contorno IBGE), FAQ e formulário de orçamento via WhatsApp

Página estática: basta abrir `index.html` ou publicar no GitHub Pages / Vercel.
